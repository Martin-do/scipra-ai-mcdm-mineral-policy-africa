# SCIPRA: Stakeholder-Centric Investment–Regulatory Policy Architecture

This repository contains the reproducibility package for the manuscript:

**Bridging the Investment-Regulatory-Stakeholder Divide: An AI-Enhanced MCDM Framework for Mineral Resource Policy Convergence in Africa**

The package supports inspection and reproduction of the SCIPRA mathematical framework and downstream PCI/RPCI calculations. The current repository does **not yet contain the complete 87-document empirical corpus described in the manuscript**, so the published NLP-SVM metrics cannot presently be claimed as independently end-to-end reproducible from this repository alone.

See [`REPRODUCIBILITY_STATUS.md`](REPRODUCIBILITY_STATUS.md) for the current audit status and remaining blockers.

## Reproducibility workflow

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Inspect the currently archived corpus and provenance notes in `data/` and `docs/`.

3. Attempt the empirical NLP-SVM + PCI/RPCI analysis:

```bash
python code/execute_full_analysis.py
```

The script now validates the actual matched corpus size. Because the manuscript reports `N=87`, it stops rather than silently presenting a smaller corpus as the full manuscript analysis.

For diagnostics only, an incomplete archived corpus can be examined with:

```bash
python code/execute_full_analysis.py --allow-partial
```

Results from `--allow-partial` are explicitly **not manuscript replication results**.

4. Reproduce downstream PCI/RPCI arithmetic from the scenario domain scores published in the manuscript:

```bash
python code/generate_tables.py
```

This checks the mathematical transformation from published `(I, R, S)` inputs to PCI/RPCI values. It does not independently reconstruct those domain inputs from the raw documentary corpus.

5. Inspect the mathematical core in isolation:

```bash
python code/pci_computation.py
```

6. Inspect stakeholder-salience utilities:

```bash
python code/plu_scoring.py
```

The P/L/U-to-SIC provenance remains under reconciliation; see `REPRODUCIBILITY_STATUS.md`.

## Cross-validation implementation

The current rework places TF-IDF vectorisation and the RBF-SVM inside a single `sklearn.pipeline.Pipeline`. This ensures vocabulary selection and IDF statistics are learned within each cross-validation training fold rather than from the complete corpus before validation.

The manuscript-reported SVM metrics should be regenerated only after the complete documented 87-record corpus and labels are restored.

## Mathematical design notes

### Non-Linear PCI

The current mathematical implementation uses a weighted harmonic mean in `pci_nonlinear()` consistent with the domain weights used by the SCIPRA framework. Any manuscript/SI equation using an unweighted harmonic mean should be reconciled explicitly before final archival release.

### RPCI normalization

The code distinguishes:

- `RPCI_raw = max(0, PCI − λσ)`
- `RPCI_norm = RPCI_raw / (1 + λ/2)`

The final manuscript and supplementary material should use one clearly identified authoritative form and label any alternative quantity consistently.
